# 🏢 中古マンション評価ウェブアプリ

中古マンションの物件ページURLを入力すると、Claude API（Web検索つき）が物件を自動評価し、
不動産にくわしくない人にもやさしいレポートを表示するスマホ優先のウェブアプリです。

## 主な機能

- **新規評価**: URLを1つ入力 →「評価する」→ 5セクション構成の評価レポートを表示
- **履歴**: 評価した物件を端末内（ブラウザのlocalStorage）に保存。タップで保存済みレポートを再表示（再計算なし）、ゴミ箱アイコンで削除、「最新の相場で再評価」も可能
- **読み取り確認カード**: レポート冒頭に読み取った物件情報を表示し、間違っていれば修正して再評価
- **エラーフォールバック**: URL不正・掲載終了・読み取り失敗時は、物件名・住所・価格・面積・階・築年の手入力フォームに切り替え
- **価格ゲージ**: 妥当価格レンジ（緑帯）・売出価格（▼）・推奨指値（│）を1本の横棒で表示。▼が緑帯より右なら一目で割高と分かる
- **信号色ルール**: 割安=緑 / 妥当=青 / やや割高=オレンジ / 割高=赤

## セットアップ

```bash
npm install
cp .env.local.example .env.local
# .env.local に ANTHROPIC_API_KEY を設定
npm run dev
```

http://localhost:3000 をスマホ幅で開いてください。

## ⚠️ 評価エンジンプロンプトの差し替え（重要）

評価ロジック本体は **`lib/evaluation-prompt.ts`** に分離されています。
お手持ちの「評価エンジンプロンプト」全文を、このファイルの `ENGINE_PROMPT` に
**そのまま・無改変で** 貼り付けてください。アプリはこの文字列を加工せずLLMに渡します。

（現在は仕様の5セクション構成に準拠したデフォルトプロンプトが入っており、
貼り付け前でも動作します。）

## 構成

| パス | 役割 |
|---|---|
| `app/page.tsx` | 3画面（入力 / 評価結果 / 履歴）の切り替えと状態管理 |
| `app/api/evaluate/route.ts` | Claude API 呼び出し（`claude-opus-4-8` + Web検索/Webフェッチのサーバーツール、`pause_turn` 継続処理つき） |
| `lib/evaluation-prompt.ts` | 評価エンジンプロンプト（ここだけ差し替える） |
| `lib/storage.ts` | 履歴のlocalStorage保存 |
| `components/` | 判定バッジ・価格ゲージ・読み取り確認カード・ローディング・履歴一覧など |

## 技術メモ

- 評価生成: LLMに「評価エンジンプロンプト + 出力フォーマット指示 + 物件URL（または手入力情報）」を渡し、
  メタ情報（JSON）とレポート本文（HTML）をマーカーで区切って受け取ります
- Web取得: Claude APIのサーバーツール `web_search` / `web_fetch` を有効化しており、
  アプリ側でのスクレイピングは不要です
- レポートHTMLはサーバー側で `<script>`/`<style>`/イベント属性を除去してから描画します
- 1回の評価に2〜5分かかることがあります。サーバーレス環境にデプロイする場合は
  実行時間上限（`maxDuration = 300`）に対応したプランを利用してください
- 履歴は端末内保存のみ（ログイン不要）。複数端末で共有したい場合はログイン+DB構成への変更が必要です
